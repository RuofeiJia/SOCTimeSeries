## Introduction

This repository contains the data and code for the manuscript "A large global soil carbon sink informed by soil samplings". An earlier version of the manuscript was posted as a preprint on bioRxiv (<https://www.biorxiv.org/content/10.1101/2025.04.25.650716v1>). The repository now reflects the analyses used in the revised version of the manuscript.

**To contribute to the Global Soil Organic Carbon Time Series (SOCTS) Database, contact Ruofei Jia ([rfjia\@mit.edu](mailto:rfjia@mit.edu){.email}).**

All scripts were run in R Version 4.3.2

## "data" folder contains

-   region_division_df.rda
    -   Dataframe with region division modified from Pan et al. (2024). It was used to generate proportion_decade_df.rda
    -   Each row contains centered latitude, centered longitude, and the region name of a 0.5 degree pixel
-    SOC_data_for_analysis_metadata.csv
    -   Description of data used for analysis. This dataset (SOC_withNewData_for_analysis.rda) will be published with the manuscript
-   Other files not included in this repository can be generated by running 00_download_prepare_spatial_data.R, 01-1_process_repeated_SOC_data.R, 01-2_process_and_add_singletime_SOC_data.R, in order

## "results" folder contains

-   SOC_change_table.xlsx
    -   All main and supplementary tables generated from script Tables_all.R and data used to visualize Fig. 3C.
-   Other files not included in this repository can be generated by running 02_analysis.R, 03_prediction.R, and 04_upscale.R in order, after recovering files in the "data" folder.

## "scripts" folder contains

-   00_download_prepare_spatial_data.R
    -   Script used to download and process all spatial data
-   01-1_process_repeated_SOC_data.R and 01-2_process_and_add_singletime_SOC_data.R
    -   process the raw soil data (repeated and single-time SOC samplings) into a dataset ready for statistical analysis
-   02_analysis.R
    -   Conducts a Wilcoxon test on the soil C rate of change between young and old forests
    -   Fits the Bayesian GAMM model to SOC samplings data
    -   Diagnoses the Bayesian fitted GAMM model
-   03_prediction.R
    -   Uses the GAMM to predict SOC change per area at pixel level
-   04_upscale.R
    -   Upscales pixel-level predictions into regional and global estimates of SOC changes.
    -   Uses the upscaled results to estimate forest SOC sink (shown in Fig. 3B) and SLAND_soil (shown in Table 2)
    -   Outputs results of global and regional SOC sink estimates in the manuscript
-   Figure1.R, Figure2.R, Figure3.R, Figure4.R, Figures_supplementary
    -   Generate main and supplementary figures
-   Tables_all.R
    -   Generates main and supplementary tables
