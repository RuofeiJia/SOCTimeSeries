## Introduction

This repository contains the data and code for the manuscript "A large global soil carbon sink informed by soil samplings". An earlier version of the manuscript was posted as a preprint on bioRxiv (<https://www.biorxiv.org/content/10.1101/2025.04.25.650716v1>). The repository now reflects the analyses used in the revised version of the manuscript.

**To contribute to the Global Soil Organic Carbon Time Series (SOCTS) Database, contact Ruofei Jia ([rfjia\@mit.edu](mailto:rfjia@mit.edu){.email}).**

All scripts were run in R Version 4.3.2

## "data" folder contains

-   pan_regions.gpkg
    -   Polygons of world's regions for plotting
-   region_division_df.rda
    -   Dataframe with region division modified from Pan et al. (2024). It was used to generate proportion_decade_df.rda
    -   Each row contains centered latitude, centered longitude, and the region name of a 0.5 degree pixel
-   SOC_timeseries_for_analysis_metadata.csv
    -   Description of data used for analysis. This dataset will be published with the manuscript
-   Other files not included in this repository can be generated by running 00_download_prepare_spatial_data.R, 01_process_SOC_timeseries_data.R, in order

## "results" folder contains

-   Files can be generated by running 02_analysis.R, 03_prediction.R, and 04_upscale.R in order, after recovering files in the "data" folder.

## "scripts" folder contains

-   00_download_prepare_spatial_data.R
    -   Script used to download and process all spatial data
-   01_process_SOC_timeseries_data.R
    -   process the raw soil organic carbon (SOC) time series data into a dataset ready for statistical analysis
-   02_analysis.R
    -   Conduct a Wilcoxon test on the soil C rate of change between young and old forests
    -   Fit the Bayesian GAMM model to SOC samplings data
    -   Diagnose the Bayesian fitted GAMM model
-   03_prediction.R
    -   Use the GAMM to predict SOC change per area at pixel level
-   04_upscale.R
    -   Upscale pixel-level predictions into regional and global estimates of SOC sinks.
    -   Output results of global and regional SOC sink estimates in the manuscript
-   Figure1.R, Figure2.R, Figure3.R, Figure4.R, Figures_supplementary
    -   Generate main and supplementary figures
-   compute_sland_indomain.R, fig_sland_fraction.R, fig_trendy_comparison.R
    -   Generate results for Figure4.R
-   Tables_all.R
    -   Generate all tables
